## Summary

Basically, this is meant to emulate the look and feel of macOS Tahoe. Built using Next.js

## References

Nomenclature and some design choices (the rest are from my own Mac) originate from here:

- Menu bar: https://support.apple.com/en-gb/guide/mac-help/mchlp1446/mac
- Dock: https://support.apple.com/en-gb/guide/mac-help/mh35859/15.0/mac/15.0

## Media sources

### Dock icons

For each icon:

- Find the item in Finder
- Right-click the item
- Click "Get Info"
- In the top left, click the icon
- Do <kbd>Ctrl</kbd>+<kbd>C</kbd>
- Open the Preview app
- Go to File -> New From Clipboard (or <kbd>Cmd</kbd>+<kbd>N</kbd>)
- Right-click the first image
- Click "Export As"
